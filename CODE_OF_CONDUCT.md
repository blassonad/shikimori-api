# Code of Conduct

## Наше обязательство

Мы стремимся к открытому, уважительному и безопасному сотрудничеству для всех участников независимо от опыта, языка, происхождения, гендерной идентичности и выражения, сексуальной ориентации, инвалидности, внешности, возраста, религии или иных личных характеристик.

## Ожидаемое поведение

Конструктивно обсуждайте код и идеи, а не людей. Уважайте разные технические подходы, аргументируйте замечания воспроизводимыми фактами, принимайте обратную связь добросовестно и помогайте новичкам. Сообщайте security concerns приватно, не раскрывая secrets и персональные данные.

## Недопустимое поведение

Недопустимы оскорбления, harassment, threats, hate speech, sexualized language or imagery, deliberate intimidation, sustained disruption, doxxing, публикация чужих private information, несанкционированное раскрытие security report или иных confidential материалов. Недопустимо использовать project channels для преследования, спама либо распространения malicious content.

## Область действия

Кодекс действует в issues, pull requests, discussions, reviews, commits, releases, GitHub Actions logs и других project communication spaces, а также при публичном представлении проекта.

## Enforcement

О нарушении сообщайте через [private GitHub Security Advisory](https://github.com/blassonad/shikimori-api/security/advisories/new), пометив обращение как conduct report и не включая лишние персональные данные. Reports обрабатываются конфиденциально в разумных пределах. Maintainer оценивает контекст и может вынести предупреждение, удалить контент, временно ограничить взаимодействие или permanently ban участника. Серьёзные либо повторные нарушения ведут к более строгим мерам.

Решения должны быть пропорциональны поведению и учитывать безопасность пострадавших. Если maintainer сам вовлечён в инцидент, он должен воздержаться от единоличного решения и привлечь независимого trusted reviewer.
